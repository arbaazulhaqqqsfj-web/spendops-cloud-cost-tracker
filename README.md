*SpendOps - Cloud Cost Tracker*
SpendOps is a student-focused cloud cost tracking dashboard built with HTML, CSS, and JavaScript. The project starts as a frontend MVP using mock AWS usage data and is designed to evolve into a real serverless AWS application.

*Project Overview*
Cloud costs can become confusing for students and beginners using AWS Free Tier. SpendOps helps users understand estimated cloud spend, monitor service usage, track free-tier limits, and identify possible cost risks before they become surprise bills.

This project is part of my cloud computing learning journey and is built to demonstrate practical understanding of frontend development, cloud architecture, serverless systems, and cost monitoring.

*Features*
- Monthly cloud spend summary
- Budget usage tracker
- Forecasted end-of-month cost
- AWS service cost breakdown
- Free Tier usage meters
- Cost risk alerts
- Cost-saving recommendations
- Cloud architecture roadmap
- Light and dark theme toggle
- Editable monthly budget using browser storage

*Tech Stack*
Current frontend version:
- HTML
- CSS
- JavaScript
- LocalStorage
- Mock AWS cost data

Planned cloud version:
- AWS S3
- AWS CloudFront
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- Amazon CloudWatch

*Why This Project Is Cloud-Related*
SpendOps is not just a normal frontend dashboard. It is designed around real cloud operations concepts:
- Tracking cloud service usage
- Understanding monthly cloud spend
- Monitoring budget risk
- Working with AWS Free Tier limits
- Planning serverless backend architecture
- Preparing for cloud monitoring and alerting
